# Folio

Design system Vue 3 sobre et éditorial, accessible par défaut.

- **Natif d'abord** : les champs reposent sur les éléments HTML natifs.
- **Aucune fuite de style** : aucun reset global, toutes les valeurs passent par les tokens.
- **Aucune chaîne en dur** : tout texte visible vient des props ou des slots.
- **Chaque story est un test** : interactions (`play`) et contrôle axe, exécutés par Vitest dans Chromium.
